Automated backup and restore testing Experimental: This is an experimental feature. To enable this feature, set android.experimental.testSuiteSupport=true and android.experimental.enableBackupTest=true in your gradle.properties file. AGP 9.5.0-alpha09 adds automated backup and restore tests to help you catch missing or unusable restored data before you release. Declare a test suite in the testOptions.backupTests block. AGP then builds and runs JUnit 5 tests that add test data to your app on connected devices, back up and restore the app, and check that the data is intact. You can test local, cloud, and device-to-device transfers, and the results appear in an HTML test report. For more information, see Automated backup and restore testing and the backup and restore testing release notes .
