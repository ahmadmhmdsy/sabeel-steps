**F1 (High, bug).** Lint is not advisory here: `lintDebug` **fails** (exit 1, "BUILD FAILED in 2m 7s") with 5 `MissingPermission` errors at `Notifications.kt:148,165`, `StepCounterService.kt:226`, `WalkTrackingService.kt:267,416`. The call sites are guarded (permission check or `runCatching`) so these are largely false-positive-adjacent, but the project's own DoD item "lintDebug has no Error-severity issue introduced by us" (`docs/product/spec.md:130`) is unmet and any CI gate rejects the tree. Fix with explicit checks or annotated suppressions until the task exits 0.

**F2 (High, gap).** No `.git` exists anywhere; the root has sources plus `.dsh/` (22 files, 4.4 MB internal agent transcripts), `.gradle/`, `.kotlin/`, `dist/`, `local.properties`. `local.properties` holds only `sdk.dir` (no secret), but `.dsh/` transcripts contain host paths/usernames and internal prompts, and caches are noise. Without VCS there is no provenance, diffability, rollback or safe collaboration; README build identity rests on an external evidence batch the repo cannot regenerate.

**F3 (High, risk→bug).** Lint flags `AppBundleLocaleChanges` (`AppLocale.kt:30`) because the app switches locale at runtime with no Play Core language download and no `language.enableSplit=false`. Under AAB delivery, the Arabic split is installed only when device locale demands it; the in-app switch then selects resources that are absent, so AR users on EN devices get English text. Bilingual EN/AR is a first-class promise, so fix before any Play upload and verify with `bundleRelease` output (the debug APK packages all locales, masking the bug).

**F4 (High, gap).** `assembleRelease` succeeds but emits only `app-release-unsigned.apk` (7,863,634 B, SHA-256 `A64F8995F1E89086530E0B14F38A1663CFCB938C34344CA19847286807B219FD`); apksigner: "DOES NOT VERIFY / Missing META-INF/MANIFEST.MF". `isMinifyEnabled=false` (`app/build.gradle.kts:27`), empty proguard file, `versionCode=1`, no signingConfig, no CI, no `bundleRelease` ever exercised. The release path is unproven: no R8/resource-shrinking regressions caught, no deterministic version identity, no installable artifact. Expected pre-publish, but the largest release gate.

**F5 (Medium, bug/risk).** My first `:app:clean` **failed** (exit 1, 15 s) with `IOException: Unable to delete directory … app/build`, listing locked lint-cache jars; after `gradlew --stop` (`3 Daemons stopped`) clean succeeded and the full rebuild passed. However the clean-built debug APK is **not byte-identical** to dist: 11,366,468 B / `D07D5B3C…EB57` vs 11,488,512 B / `32469019…B9E`, with identical 180 entries but 9 dex entries permuted (one differs by 52 B) — so the README hash identifies one build instance, not the tree; reproducibility needs a provenance record (toolchain, lockfiles, clean hash), not a single artifact hash.
