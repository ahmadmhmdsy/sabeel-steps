Two of the plan's own abstractions should be cut outright. StatCardGrid, the largest row, is a spec-growth trap: the cost at each site is the entries, not the stacked branch, and the first card that needs an action or a tone grows the type for every other grid. Their corrected value is a parameterised -10, not -20.

The safe-helper rule the plan should have used: no parameter whose value is fixed at every call site, and a third call site must not require a new parameter. By that rule two of the six helpers are cut and a third - the settings row shell - must keep its font-scale read at the call site.

The oracle install is the largest hidden cost. 180 captures at 90-150 s each is 4 to 7 unaccounted engineer-days; the states are device-dependent, the saved AVD is sensorless, the recorded validation image returns blank screencaps, and there is no owner, no pinned image, no committed hashes, no non-author adjudicator. The customer's denominator is valid as framing and a category error as a code KPI.
